# First Rails Application

This repository preserves my first Ruby on Rails application, created in 2014 while following Michael Hartl's Ruby on Rails Tutorial.

It is an early learning project rather than a finished product. The repository contains the generated Rails application structure, SQLite configuration, default test setup, and framework dependencies, but no completed user-facing feature or custom route.

## Original stack

- Ruby on Rails 4.0.8
- SQLite
- Sass
- CoffeeScript
- jQuery
- Turbolinks

## Running the project

The dependency versions are historical and may not install on a current Ruby environment. With a compatible Ruby and Bundler version, the original development flow was:

```bash
bundle install
bin/rails server
```

## Project status

Archived. The value of this repository is the timestamped starting point in my development history, so the application has not been upgraded to a modern Rails release or presented as maintained software.
